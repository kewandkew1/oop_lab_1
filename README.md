# OOP Lab 1 – Data Loading and Table Operations

## Lab Overview

This lab introduces basic object-oriented programming (OOP) concepts by working with real-world tabular data from a CSV file.  
You will:

- Load data from Cities.csv using the DataLoader class.
- Wrap the list of dictionaries in a Table class.
- Perform common data operations such as filtering rows and aggregating column values using higher-order functions and lambdas.

The goal is to practice:
- Class design
- Encapsulation of behavior inside methods
- Using lambda functions with filter- and aggregate-style operations
